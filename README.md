
Тесты

Добавление книг
- добавление новой книги
- у новой книги жанр пустой
- книга с именем длиннее 40 символов не добавляется
- повторно книга не добавляется

Работа с жанрами
- установка корректного жанра
- запрет несуществующего жанра
- получение книг по жанру

Детские книги
- книги с возрастным рейтингом не попадают в список для детей

Избранное
- добавление книги в избранное
- запрет дубликатов в избранном
- удаление книги из избранного
